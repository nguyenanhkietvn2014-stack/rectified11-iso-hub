RECTIFIED 11 ISO HUB — CHỈ CÒN NÚT TẢI ISO

Gói website này đã bỏ các nút Tải ZIP và phần thông báo ZIP chưa cấu hình. Ba nút Tải ISO vẫn trỏ đến ba liên kết MEGA đã cung cấp.

CẬP NHẬT WEBSITE GITHUB PAGES ĐANG CÓ
1. Giải nén ZIP này trên máy tính.
2. Mở repository GitHub của website.
3. Chọn Add file > Upload files.
4. Tải lên index.html và downloads.js trong gói đã giải nén. Nếu GitHub báo cập nhật tệp hiện có, chấp nhận thay thế.
5. Nhập thông điệp như Remove ZIP buttons, rồi nhấn Commit changes.
6. Mở website đã xuất bản và nhấn Ctrl+F5 để tải lại. Kiểm tra chỉ còn ba nút Tải ISO.

Không tải các file ISO lên repository; chúng vẫn được lưu tại MEGA. Gói này không chứa ISO.
